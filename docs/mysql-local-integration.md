# 本地 MySQL 源库联调

本地合成数据接口验证，不是校方现场部署或验收。平台业务库存储仍为 SQLite，源库使用真实 MySQL 中间表/只读视图。

## 配置

由实施人员在服务端配置 `SCHOOL_DB_HOST`、`SCHOOL_DB_PORT`、`SCHOOL_DB_USER`、`SCHOOL_DB_PASSWORD`、`SCHOOL_DB_DATABASE`，需要 TLS 时配置 `SCHOOL_DB_SSL_CA`。不得把凭据填写到浏览器或提交仓库。仅授予源中间表/视图的 SELECT，禁止写入和结构修改权限。

上线管理 → 校方数据源：映射源唯一标识、学号、可选班级名称、项目编码、带时区完成时间、步骤 JSON、更新时间。班级字段配置后校验与学生归属一致。步骤 JSON 用项目步骤 ID 为键，值为布尔通过状态或含 passed/reason 的对象；规范化关系表须由源库 DBA 提供适配视图。来源系统/表/字段映射改变时重置检查点，历史记录保留；同来源同标识内容变化会隔离而非覆盖。

## 检查

数据库联通与追溯界面从实际源库读取版本、表结构、记录数及账号授权，后端保守检查是否仅 USAGE/SELECT。该检查不返回连接口令或原始授权语句。来源追溯按当前来源过滤，展示批次、源标识、原始完成时间及关联成绩。

自动同步按配置调度。手动增量同步和完整幂等重读均经管理员权限及同一运行锁。完整重读不清除成绩，重复跳过，内容变化隔离。源查询在只读一致性事务内运行，查询后回滚。

运行与备份：创建业务库/配置加密备份后，恢复到独立临时目录，校验哈希、完整性、外键及配置一致性；不覆盖当前运行库。恢复验证接口仅管理员可用。源数据库的备份仍由源库所有者管理，不以平台只读接入接管。

## 本轮证据

2026-10-28，MySQL 8.4.13，本地合成源数据1005条（正常1000、重复1、异常4）。首次同步约5.14秒；同批完整重读新增0。源数据与结构哈希在同步前后相同；写入请求被MySQL1142拒绝。后台首次启动调度测试清空隔离环境检查点后新增1条，不调用手动同步接口，不代表已连续观察日级调度。独立CSV另导入1000条，最终成绩2001条。加密备份恢复包含2001条成绩，9项配置一致性通过。
