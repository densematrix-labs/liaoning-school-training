# 辽轨实训 Demo 角色化界面设计简报

## 受众

- 学生：只查看本人成绩、能力图谱、诊断报告，并提交本人实训后的环境图片。
- 教师：查看本人负责班级、全班学生成绩与能力分布，为指定学生生成诊断报告。
- 管理员：查看全校班级和学生范围，管理能力体系、实训室与数据同步状态。

## 核心工作流

- 学生登录后先看到“我的学习概览”，从最近成绩进入能力短板和诊断报告。
- 教师登录后先看到“教学工作台”，选择班级后查看学生、成绩分布并生成报告。
- 管理员登录后先看到“系统管理台”，确认数据规模、基础配置和同步状态，再进入管理功能。

## 信息层级

1. 当前身份、数据范围和最重要的状态。
2. 该角色的核心指标与主要操作。
3. 历史记录、明细和辅助信息。

## 视觉方向

沿用现有深蓝工业控制台风格，以铁路信号青色为主强调色；减少无业务含义的装饰，强化身份标签、权限边界、状态灯和紧凑数据视图。三种角色使用相同视觉系统，但拥有不同首页、导航和信息密度。

## 响应式与约束

- 桌面端使用固定侧栏，移动端改为可横向滚动的顶部角色导航，正文不产生横向溢出。
- 不改变现有 React、Tailwind、Recharts 技术栈。
- 所有关键页面必须有加载态、空态和可读错误提示。
- Demo 数据落入持久化 SQLite；未来通过 `DATABASE_URL` 切换到校方 MySQL。
- LLM 密钥只存在后端环境变量，不进入前端、仓库或日志。
