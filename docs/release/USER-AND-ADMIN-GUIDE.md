# 使用、配置与培训材料

## 学生

登录后只能看本人数据。成绩页按项目/日期筛选，打开单次明细核对逐步骤状态、分值、规则和能力依据。能力页看大类/子类、达标线和变化趋势；没有足够实训证据不代表已经达标。

诊断页选择一条成绩生成单次报告，或填开始/结束日期生成阶段报告。显示提交、处理、成功或失败，成功后可查阅/下载，失败不会丢失原成绩。环境结果页可以选本人真实实训、对应实训室并上传现场 JPEG/PNG/WebP（≤10MB）；由教师复核最终结论。没有摄像头也可以使用。上传前确认画面不含无关人脸、学号等不必要身份信息。

## 教师

班级概览选择授权班级和时间范围，查看成绩分布、能力分布、共性薄弱项与毕业达标，导出班级统计 CSV。学生详情与成绩页用于对账。报告中心按学生生成并下载报告。不能通过改 URL 查看其他教师班级。

环境检查页选择授权班级/学生，上传现场图或查看设备已产生的记录。比较标准图和现场图，保留 AI 原始结果，选择确认、修改或驳回，填写分项意见和整体备注。模型低置信度/模糊图片尤其需要复核；静态图片不能证明断电、完整操作流程或内部设备安全。

## 管理员：初始化顺序

1. “上线管理 → 基础数据”：下载对应 CSV 模板。先专业 → 教师/学生账号 → 班级 → 学生 → 实训室 → 大类能力 → 子能力 → 实训项目。父对象 ID 可从列表获取。
2. 密码至少 12 位；首次安装运维管理员使用随机长口令。先校验批量文件，再导入有效行；每行返回结果。导入更新使用已有 ID，不能靠同名自动猜测身份。
3. 项目规则在 JSON 配置里维护步骤 ID/名称/顺序/score/failed_score/weight/enabled、能力映射和 `scoring_rules.code/repeat_mode/enabled`。保存后有版本记录；真实导入必须匹配完整有效步骤。
4. 能力停用/账号停用保留历史，禁止硬删破坏引用。改密码/停用/角色变更使原会话失效；当前管理员不能停用/降级自己。
5. 实训室上传教师确认的标准图片，不能把模拟图片当真实校方标准。
6. “真实实训导入”支持 UTF-8 CSV/XLSX；先导入一条样例对账，再批量。源数据时间没有时区按 Asia/Shanghai 解释，库存 UTC；推荐显式 +08:00。来源/源 ID 必须稳定且唯一。
7. “校方数据源”填写映射和定时策略；凭据由实施人员在服务器配置。没拿到数据字典时不要猜字段。只读通用视图约定见 DATA-AND-API.md。
8. “操作审计”查看用户、对象、结果、时间；“运行与备份”检查心跳/真实连接、加密备份。任何凭据不在页面或群聊传递。
9. 旧基础配置仍可查看/编辑和执行明确重算，release 保存前后规则与分数证据；旧演示同步入口在 pilot 下拒绝执行。正式数据入口为上线管理。

## 培训连续操作脚本

演练数据必须标注合成/脱敏，与 pilot 真实学校库隔离：

- 管理员导入正常、重复、缺步骤三类记录；展示数量、错误行，导出异常；重复执行新建数量为零。
- 教师打开一条失败步骤，逐项核对状态/得分/总分/能力；管理员调整演练规则后明确重算，展示前后记录。
- 学生看本人雷达图；教师看班级汇总及本人学生详情；分别尝试越权，确认接口拒绝且没有数据泄漏。
- 在 AI 服务许可且可达时生成一份报告，核对成绩、失败步骤、薄弱能力，再按时间范围生成阶段报告。
- 上传现场图、处理到完成、教师修改/备注、重新打开显示原始/复核结果及人/时间。摄像头录制不替代网页上传演示。
- 执行加密备份，到新空目录恢复，核对记录数与登录；故意断开 AI 验证失败说明和历史数据仍可读。

培训完成记录必须填写实际日期、讲师、参加人员、版本、演练环境、问题处理结果和校方确认，不提前填“已培训”。正式演示视频必须连续实操录制，不能用静态截图充当视频。
