# 辽轨 Demo 功能参数技术设计

## 架构与数据流

继续使用 React + FastAPI + SQLAlchemy + SQLite。新增三条可追溯链路：

1. `TrainingRecord.steps_data → ScoringRule/项目步骤定义 → Score.details → AbilityProfile`
2. `ReportTask(pending/running/completed/failed) → 百炼 → DiagnosticReport`
3. `EnvironmentCheck(AI 原始结果) → EnvironmentReview(人工结果/状态/备注/人员/时间)`

管理员修改评分规则或步骤映射后，通过重算服务按指定记录重新生成步骤分、总分及能力画像。能力计算统一读取项目当前映射与成绩步骤证据，禁止另存随机能力值作为来源。

## API 组件

- 成绩：班级多条件查询、单次详情、记录重算。
- 能力：个人/学生/班级接口全部复用统一权限校验；详情返回子能力及支撑证据。
- 教师概览：按班级和时间范围返回完成情况、成绩分布、能力分布、达标人数和共性薄弱能力。
- 管理配置：读取/更新项目步骤、评分规则、能力映射、阈值与标准图；触发重算。
- 报告任务：创建任务、查询状态、获取报告；后台任务完成真实模型调用。
- 环境复核：查询检查详情、提交确认/修改/驳回和备注，原始结果不可变。
- Mock 同步：创建包含正常、重复、异常记录的演示批次，持久化统计、异常明细并支持导出。

## 错误处理

- 无权限统一返回 403，不返回目标业务数据。
- 规则、映射或步骤数据不完整时，重算失败并记录具体字段和记录。
- AI 请求超时或上游失败时任务进入 `failed`，保存失败原因并允许重试。
- 环境复核只允许教师处理授权学生记录，管理员可处理全部演示记录。

## 前端设计简报

- 受众：教师、管理员及评标演示人员。
- 主流程：选择对象 → 查看证据 → 执行动作 → 验证持久化结果。
- 信息层级：状态/异常/关键指标优先，证据与配置其次，装饰最低。
- 视觉方向：延续现有深蓝铁路工业控制台，增加清晰的状态徽标、证据抽屉和紧凑数据表，不重做品牌风格。
- 密度：桌面端高密度但可扫描；移动端将表格降级为分组卡片，禁止水平裁切关键操作。
- 可访问性：按钮有禁用态、加载态和错误提示；状态不用颜色单独表达。

## 页面范围

- `/class-scores`：筛选、统计、明细抽屉。
- `/classes`：班级概览、学生综合详情下钻。
- `/batch-reports`：任务状态与指定单次记录。
- 教师环境检查页：历史任务、AI/人工双结果及复核。
- 管理配置页：项目规则、映射、阈值、标准图片、Mock 同步。
- 学生能力与成绩页：子能力、支撑证据和单次步骤明细。

## 测试策略

- 单元：计分、映射、能力聚合、报告状态、环境复核状态机。
- 权限：学生本人、教师授权班级、教师跨班、管理员四组用例。
- 集成：规则修改→重算→成绩变化→能力变化；报告任务；环境复核重开。
- 性能：50 并发访问基础查询；常规接口 3 秒内，统计/能力汇总 10 秒内，并输出测试结果。
- 视觉：所有受影响页面桌面与移动截图，经设计评审达到 8/10。
